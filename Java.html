Java Fundamentals & Language Comparison

Overview

This week introduces Java fundamentals and compares Java with C, C++, Python and JavaScript.

Core Java vs Advanced Java

Core JavaAdvanced Java
Fundamental language concepts, OOP, data types, control statements and collections.Enterprise and web technologies such as JDBC, Servlets, JSP and frameworks.
Used for standalone and general-purpose programs.Used for database-driven and web-based applications.

Applets, Servlets, JDBC and Web Concepts

  • Applets: legacy browser-embedded Java programs.
  • Servlets: server-side Java components handling HTTP requests and responses.
  • JDBC: Java API for connecting to relational databases.
  • Cookies store small client-side values; sessions maintain server-side user state.
  • Spring Boot simplifies Spring application setup and configuration.

Programming Language Comparison

LanguageDeveloperExecutionOOPCommon use
JavaJames Gosling / Oracle-led ecosystemCompiled to bytecode, run on JVMYesEnterprise, Android, backend
CDennis Ritchie / Bell LabsCompiledNo (procedural)Systems, embedded
C++Bjarne StroustrupCompiledYesSystems, games, high performance
PythonGuido van RossumUsually interpreted/bytecode VMYesAI, automation, data science
JavaScriptBrendan EichJIT/interpreted by JS enginesYes (prototype-based)Web frontend/backend

Database, memory and platform

  • Java: JDBC, automatic garbage collection, JVM portability.
  • C/C++: database libraries/connectors; manual or explicit memory control.
  • Python: DB-API drivers/ORMs; automatic memory management.
  • JavaScript: database drivers and browser storage; automatic memory management.

Conclusion

Each language serves different needs. C and C++ are strong for systems and performance, Java for enterprise applications, Python for AI and data science, and JavaScript for web development. The best choice depends on application requirements, platform, performance and developer productivity.

Install & Configure JDK 26 on Ubuntu

Aim

To download, install and configure OpenJDK and Oracle JDK SE 26 in the Ubuntu operating system.

Requirements

  • Ubuntu operating system
  • Internet connection
  • Terminal with sudo access

OpenJDK installation

sudo apt update
sudo apt install openjdk-26-jdk
java -version
javac -version

Package availability depends on the Ubuntu release and configured repositories. If the package is unavailable, use the official OpenJDK distribution archive/package appropriate for your system.

Oracle JDK SE 26 installation

  1. Open the official Oracle Java downloads page.
  2. Download the Linux x64 or ARM64 archive matching the machine architecture.
  3. Extract the archive to a suitable directory such as /usr/lib/jvm.
  4. Set JAVA_HOME and update PATH.
sudo mkdir -p /usr/lib/jvm
# Extract the downloaded archive into /usr/lib/jvm
sudo nano /etc/profile.d/jdk.sh

export JAVA_HOME=/usr/lib/jvm/jdk-26
export PATH=$JAVA_HOME/bin:$PATH

source /etc/profile.d/jdk.sh
java -version
javac -version

Verify configuration

echo $JAVA_HOME
which java
java --version
javac --version

Use the actual extracted directory name in JAVA_HOME.

Object-Oriented Programming in Java

Aim

To practise the object-oriented features of Java using simple programs.

Key concepts

  • Class and object: a class defines state and behaviour; an object is its instance.
  • Encapsulation: keep fields private and provide controlled methods.
  • Inheritance: extend an existing class using extends.
  • Polymorphism: method overloading and overriding.
  • Abstraction: define essential behaviour using abstract classes and interfaces.

Sample program

class Student {
    private int rollNo;
    private String name;
    Student(int r, String n) {
        rollNo = r; name = n;
    }
    void display() {
        System.out.println(rollNo + " " + name);
    }
}
public class Main {
    public static void main(String[] args) {
        Student s = new Student(101, "Ravi");
        s.display();
    }
}

Procedure

  1. Create a Student class with private fields.
  2. Initialize fields through a constructor.
  3. Create an object in main and call display().
  4. Compile and run the program.

Expected output

101 Ravi

Result

Class creation, object construction, encapsulation and method invocation are demonstrated.

Exception Handling and Multithreading

Supplementary practice content — confirm the exact experiment title with your official lab manual.

Aim

To understand exception handling and basic multithreading in Java.

Key concepts

  • try encloses statements that may throw an exception.
  • catch handles a matching exception.
  • finally is used for cleanup.
  • throw and throws work with exception propagation.
  • A thread is an independent path of execution; call start() to begin it.

Sample program – Exception

public class ExceptionDemo {
    public static void main(String[] args) {
        try {
            int result = 10 / 0;
            System.out.println(result);
        } catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero");
        } finally {
            System.out.println("Execution completed");
        }
    }
}

Sample program – Thread

class Task extends Thread {
    public void run() {
        System.out.println("Thread is running");
    }
}
public class ThreadDemo {
    public static void main(String[] args) {
        new Task().start();
    }
}

Procedure

  1. Execute a division operation inside try.
  2. Handle ArithmeticException in catch.
  3. Observe the finally block.
  4. Extend Thread, override run(), and invoke start().

Result

Exception handling and basic thread execution are demonstrated.

JDBC Connectivity and PreparedStatement

Supplementary practice content — confirm the exact experiment title with your official lab manual.

Aim

To connect a Java application to a relational database and retrieve records with PreparedStatement.

Key concepts

  • DriverManager obtains a database Connection.
  • Connection represents the database session.
  • PreparedStatement executes parameterized SQL using ? placeholders.
  • ResultSet reads rows returned by SELECT.
  • SQLException reports database access errors.

Sample program structure

String url = "jdbc:mysql://localhost:3306/college";
String user = "root";
String password = "your_password";
String sql = "SELECT id, name FROM student WHERE id = ?";
try (Connection con =
         DriverManager.getConnection(url, user, password);
     PreparedStatement ps = con.prepareStatement(sql)) {
    ps.setInt(1, 101);
    try (ResultSet rs = ps.executeQuery()) {
        while (rs.next()) {
            System.out.println(rs.getInt("id") + " "
                + rs.getString("name"));
        }
    }
} catch (SQLException e) {
    e.printStackTrace();
}

Procedure

  1. Start MySQL and create a college database and student table.
  2. Add MySQL Connector/J to the project.
  3. Update URL, username and password for the local database.
  4. Prepare the SELECT query, set its parameter and execute it.
  5. Read the returned rows through ResultSet.

Use your own local database credentials. Do not include a real password in a public submission.

Result

Java retrieves a selected student record from MySQL using JDBC PreparedStatement.

JDBC Template with In-memory Database (H2)

Dependencies

  • Spring Web
  • Spring Data JDBC
  • H2 Database

Author class

public class Author {
  private String firstName;
  private String lastName;
  public Author(String firstName, String lastName) {
    this.firstName = firstName;
    this.lastName = lastName;
  }
  // getters and setters
}

AuthorService – main operations

@Service
public class AuthorService {
  @Autowired JdbcTemplate jdbcTemplate;

  @PostConstruct
  public void postConstruct() {
    jdbcTemplate.execute("DROP TABLE IF EXISTS author");
    jdbcTemplate.execute(
      "CREATE TABLE author (first_name varchar(255), last_name varchar(255))");
    jdbcTemplate.update(
      "INSERT INTO author(first_name,last_name) VALUES (?,?)",
      "ramesh", "it");
    jdbcTemplate.update(
      "INSERT INTO author(first_name,last_name) VALUES (?,?)",
      "harshith", "it");
  }
}

application.properties

server.port=83
spring.h2.console.enabled=true

H2 console: http://localhost:83/h2-console. Username: sa; password blank. Use the JDBC URL shown in the application startup console.

Result

Student entity

@Entity
public class Student {
  @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
  private Long id;
  private String name;
  private String city;
  // constructors, getters and setters
}

Repository

public interface StudentRepository
    extends JpaRepository<Student, Long> { }

Controller endpoints

@RestController
public class StudentController {
  @Autowired StudentRepository repo;

  @GetMapping("/")
  public String home() {
    return "Spring Boot + H2 + JPA Example Running!";
  }

  @GetMapping("/add")
  public String add(@RequestParam String name,
                    @RequestParam String city) {
    repo.save(new Student(name, city));
    return "Student Added Successfully!";
  }

  @GetMapping("/students")
  public List<Student> getStudents() {
    return repo.findAll();
  }
}
